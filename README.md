# 健身计划模拟器 · THE DAILY BURN

一款【报纸杂志风】的健身计划单页应用：把每日训练计划排版成老式双页对开报纸，前后翻页即切换每日安排，可打卡、可编辑、可拍照记录，还能自己发「朋友圈」投稿。

## 功能

- 双页对开报纸排版 + 3D 仿真翻页
- 7 天训练周期 × 30 天计划（含 37 个动作的「怎么做 / 注意事项」百科）
- 每日勾选打卡、实时进度统计
- 点击文字即可编辑动作与备注、每日登记体重
- 打卡拍照（黑白网屏报纸滤镜）
- 「健身圈」随机圈友动态 + 自己投稿（文字 + 配图）

## 使用

- 在线体验：https://wait-yyy.github.io/fitness-plan-simulator/
- 或直接下载 `index.html`，双击用浏览器打开即可（无需安装、无需联网）

## 技术

纯静态单文件：HTML + CSS + 原生 JavaScript，无框架、无构建。

## 提示

- 状态保存在浏览器会话内，刷新即清空（未做持久化）
